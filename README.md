## 计算口径

**用量比例（默认口径）**：输入 2.91% / 缓存命中 96.81% / 输出 0.27%

> 若你的实际用量特征不同，套用下面公式，把三个比例换成你自己的即可。

平均每 1M tokens 费用 = 输入单价 × 输入比例 + 缓存命中单价 × 缓存命中比例 + 输出单价 × 输出比例

每 1 亿 tokens 费用 = 平均每 1M tokens 费用 × 100

## 核心发现

1. **智谱 Coding Plan（全价套餐）**中，**Max 非高峰（5.65 元/亿）**最便宜，但月费 1078 元门槛高；**Pro 非高峰（6.58 元/亿）**月费 538 元，性价比更均衡。
2. **官方 5 折 GLM 直充（6.26 元/亿）**是所有方案中**无需月费、无限制、且价格极低**的选择——如果你能赶上这个限时优惠，直接充就完事了。⚠️ 限时 5 折约 2 周（自 2026-08-26 起），会过期。
3. **OpenCode Go 套餐的 Flash 闲时（7.18 元/亿）**是最便宜的**无需操心峰谷**的方案，月费仅 72 元，适合不想管时间的用户。
4. **DeepSeek 官方直充**的 flash 空闲（10.42 元/亿）比官方 GLM 原价（12.51）和 Qwen 直充（13.40）都便宜，是**直充党最优选**。
5. **DeepSeek V4 Pro** 所有渠道都贵得离谱（最低 22.01 元/亿，最高 62.52 元/亿），非必要不使用。
